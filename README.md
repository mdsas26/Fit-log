# FitLog

FitLog is a responsive workout library web application built with Next.js and TypeScript. Users can explore different workouts, view detailed workout information, add workouts to their daily plan, save workouts for later, and track their workout progress.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Toastify
- Git & GitHub

## Key Features

1. **Workout Library**
   - Browse a collection of workouts with workout images, muscle groups, equipment, duration, calories, and ratings.

2. **Workout Details**
   - View detailed information about each workout including description, difficulty, sets, reps, calories, duration, and step-by-step instructions.

3. **Today's Plan**
   - Add workouts to today's plan and track total exercises, workout minutes, and estimated calories.

4. **Save Workouts**
   - Save workouts for later and access them from the Saved section.

5. **Workout Management**
   - Sort workouts by duration, calories, or rating.
   - Mark workouts as completed.
   - Remove workouts from today's plan.
   - Workout and saved data persist using LocalStorage.
